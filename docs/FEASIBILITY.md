## What this establishes

- Every return can be judged from public chain data alone: transaction status, block, sender, recipient, value and Transfer logs. No explorer, label or model is needed.
- Old transactions (2023-2025) are served identically by both RPCs of each chain, from outside and from inside GenVM, so validators can agree on them.
- The rule rejects real non-returns for the right reason: a reverted transaction (Alchemix `0x7ad3111b`), ETH the exploiter kept (GMX `0x2f210f0f`, Seneca `0x775cc19c`).
- Two returns show why the rule credits per recipient: one alETH went to Curve's address rather than Alchemix's; it counts only because the protocol adds Curve's address to the offer.
